PAPERPILOT — SIDE HUSTLE PROJECT
================================
A responsive, local-first document organizer for freelancers and small businesses.

FILES
- index.html : application structure
- style.css  : responsive styling
- script.js  : document indexing, search, categories, privacy controls

HOW TO RUN
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. Add PDF, PNG, JPG/JPEG, or TXT files (max 10 MB each).
4. Search and filter your local document records.

IMPORTANT TRANSPARENCY
This is a front-end prototype. It saves document names and metadata in browser localStorage.
It does not upload, read, or analyze file contents, and it does not use an AI model or API.
For the challenge's open-source AI requirement, a next step would be to add a locally hosted
open-weight model (for example, via Ollama) for invoice/receipt extraction, keeping files local.
